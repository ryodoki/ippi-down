## 実装の詳細

### ファイル名生成ロジック

1. 検索条件から分類情報を取得（大分類、中分類、小分類、細分類、工事名）
2. 空でない分類項目のみをリストに追加
3. 元のファイル名を追加（拡張子を除く）
4. アンダースコアで結合
5. 無効な文字を削除（サニタイズ）
6. 拡張子を追加

### フォルダ名生成ロジック

1. 検索条件から分類情報を取得
2. 空でない分類項目のみをリストに追加
3. アンダースコアで結合
4. 無効な文字を削除（サニタイズ）
5. 空の場合は「その他」を返す

## 注意事項

### 1. 空の分類項目の処理

- 空の分類項目はスキップされます
- 例: 大分類と工事名のみが設定されている場合
  - フォルダ名: `大分類_工事名`
  - ファイル名: `大分類_工事名_ファイル名.pdf`

### 2. すべての分類項目が空の場合

- フォルダ名: `その他`
- ファイル名: `ファイル名.pdf`

### 3. Windowsのファイル名制限

- 使用できない文字: `< > : " / \ | ? *`
- 最大パス長: 260文字（通常）
- これらの制限は`FileUtils.sanitize_filename`で処理されます
