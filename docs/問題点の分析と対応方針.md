**分析日**: 2026年1月13日

## 問題点

### 1. 工事名ごとでのフォルダが作成されていない

**現状**:
- フォルダ名: `国の機関_国土交通省_東北地方整備局_トンネル`
- 工事名が含まれていない
- 検索結果に複数の工事が含まれているが、すべて同じフォルダに保存されている

**原因**:
- 現在の実装では、検索条件の工事名（検索キーワード）しか使っていない
- 検索結果から各案件の工事名を取得していない
- 各ファイルのメタデータに工事名が含まれていない可能性

**対応方針**:
1. 検索結果ページから各案件の工事名を抽出
2. 詳細ページから工事名を抽出
3. `FileInfo`の`metadata`に工事名を追加
4. フォルダ名生成時に、検索条件の工事名ではなく、各ファイルのメタデータから工事名を取得

### 2. 分類ごとでの検索となっていない可能性

**現状**:
- 横浜のものが混ざっている
- 指定した検索条件で検索されていない可能性

**原因**:
- 検索フォームの送信処理で、検索条件が正しく送信されていない可能性
- 工事場所の検索条件が正しく適用されていない可能性
- 検索結果のフィルタリングが不十分な可能性

**対応方針**:
1. 検索フォームの送信処理を確認
2. 検索条件が正しく送信されているかログで確認
3. 検索結果のフィルタリング処理を確認
4. 工事場所の検索条件が正しく適用されているか確認

#### 1.3 フォルダ名生成の修正

`generate_folder_name()`メソッドを修正して、検索条件の工事名ではなく、各ファイルのメタデータから工事名を取得するようにします。

```python
def generate_folder_name(self, file_info: FileInfo) -> str:
    """フォルダ名を生成: 大分類_中分類_小分類_細分類_工事名"""
    parts = []
    
    # 検索条件から分類情報を取得
    if self.search_conditions:
        sc = self.search_conditions
        if sc.hachu_daibunrui:
            parts.append(sc.hachu_daibunrui)
        if sc.hachu_chubunrui:
            parts.append(sc.hachu_chubunrui)
        if sc.hachu_shoubunrui:
            parts.append(sc.hachu_shoubunrui)
        if sc.hachu_saibunrui:
            parts.append(sc.hachu_saibunrui)
    
    # ファイルのメタデータから工事名を取得
    if file_info.metadata and "koji_name" in file_info.metadata:
        parts.append(file_info.metadata["koji_name"])
    elif self.search_conditions and self.search_conditions.koji_name:
        # フォールバック: 検索条件の工事名を使用
        parts.append(self.search_conditions.koji_name)
    
    folder_name = "_".join(parts)
    folder_name = self.file_utils.sanitize_filename(folder_name)
    
    if not folder_name:
        folder_name = "その他"
    
    return folder_name
```
