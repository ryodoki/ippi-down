## 問題1: フォルダ名とファイル名で使用する工事名について

### 現状の問題

現在、フォルダ名とファイル名の生成において、**検索条件で入力した工事名**（`search_conditions.koji_name`）を使用しています。

しかし、ユーザーの要求は以下の通りです：
- **検索結果ページ（`List.aspx`）の各案件ごとの工事名**を使用すべき
- 検索条件で入力する工事名は、検索フィルタリングに使用するものであり、ファイル名やフォルダ名には使用しない

### 現状の実装

1. **`naming.py`**:
   - `generate_filename()`: `search_conditions.koji_name`を使用
   - `generate_folder_name()`: `search_conditions.koji_name`を使用

2. **`scraper.py`**:
   - `extract_metadata()`: 詳細ページから工事名を抽出する処理が存在する
   - しかし、`_extract_files_from_detail_page_via_postback()`では、このメソッドを呼び出していない
   - そのため、`FileInfo`の`metadata`に工事名が保存されていない

3. **`downloader.py`**:
   - `download_files()`: 各ファイルごとに`naming.generate_filename()`を呼び出している
   - しかし、`file_info.metadata`に工事名が含まれていないため、使用できない

### 修正案

#### 方針1: 検索結果ページから工事名を抽出して`FileInfo`に保存

1. **`scraper.py`の修正**:
   - `extract_file_links_from_search_results()`で、検索結果ページ（`List.aspx`）の各行から工事名を抽出
   - 各案件の詳細ページを取得する際に、工事名を`FileInfo`の`metadata`に保存
   - `_extract_files_from_detail_page_via_postback()`で、詳細ページから工事名を抽出して`FileInfo`に追加

2. **`naming.py`の修正**:
   - `generate_filename()`: `file_info.metadata.get("koji_name")`を使用（検索条件ではなく）
   - `generate_folder_name()`: 各ファイルごとに工事名を取得するため、このメソッドを削除または変更
   - 代わりに、`generate_folder_name(file_info: FileInfo)`として、各ファイルの工事名を使用

3. **`downloader.py`の修正**:
   - `download_files()`: 各ファイルごとにフォルダ名を生成するように変更
   - フォルダ名は`大分類_中分類_小分類_細分類_工事名`の形式で生成

#### 実装手順

1. **検索結果ページから工事名を抽出**:
   ```python
   # scraper.pyのextract_file_links_from_search_results()で
   for row in rows:
       # 工事名を抽出（リンクのテキストまたはテーブルセルから）
       koji_name_elem = row.find("a", href=lambda x: x and "__doPostBack" in x)
       if koji_name_elem:
           koji_name = koji_name_elem.get_text(strip=True)
           
       # 詳細ページを取得
       detail_files = self._extract_files_from_detail_page_via_postback(...)
       
       # 各ファイルに工事名を追加
       for file_info in detail_files:
           if not file_info.metadata:
               file_info.metadata = {}
           file_info.metadata["koji_name"] = koji_name
   ```

2. **詳細ページから工事名を抽出（フォールバック）**:
   ```python
   # scraper.pyの_extract_files_from_detail_page_via_postback()で
   # 詳細ページから工事名を抽出
   metadata = self.extract_metadata(detail_soup)
   if "koji_name" in metadata:
       for file_info in files:
           if not file_info.metadata:
               file_info.metadata = {}
           file_info.metadata["koji_name"] = metadata["koji_name"]
   ```

3. **`naming.py`の修正**:
   ```python
   def generate_filename(self, file_info: FileInfo, metadata: Dict[str, Any] = None, index: int = 0) -> str:
       """ファイル名を生成: 大分類_中分類_小分類_細分類_工事名_ファイル名"""
       parts = []
       
       # 検索条件から分類情報を取得
       if self.search_conditions:
           sc = self.search_conditions
           if sc.hachu_daibunrui:
               parts.append(sc.hachu_daibunrui)
           if sc.hachu_chubunrui:
               parts.append(sc.hachu_chubunrui)
           if sc.hachu_shoubunrui:
               parts.append(sc.hachu_shoubunrui)
           if sc.hachu_saibunrui:
               parts.append(sc.hachu_saibunrui)
       
       # 工事名はFileInfoのmetadataから取得（検索条件ではない）
       koji_name = None
       if file_info.metadata and "koji_name" in file_info.metadata:
           koji_name = file_info.metadata["koji_name"]
       elif metadata and "koji_name" in metadata:
           koji_name = metadata["koji_name"]
       
       if koji_name:
           parts.append(koji_name)
       
       # 元のファイル名を追加
       original_filename = file_info.filename
       if "." in original_filename:
           original_filename = original_filename.rsplit(".", 1)[0]
       parts.append(original_filename)
       
       filename = "_".join(parts)
       filename = self.file_utils.sanitize_filename(filename)
       
       extension = file_info.get_file_extension()
       if extension and not filename.endswith(extension):
           filename += extension
       
       return filename
   
   def generate_folder_name(self, file_info: FileInfo) -> str:
       """フォルダ名を生成: 大分類_中分類_小分類_細分類_工事名"""
       parts = []
       
       # 検索条件から分類情報を取得
       if self.search_conditions:
           sc = self.search_conditions
           if sc.hachu_daibunrui:
               parts.append(sc.hachu_daibunrui)
           if sc.hachu_chubunrui:
               parts.append(sc.hachu_chubunrui)
           if sc.hachu_shoubunrui:
               parts.append(sc.hachu_shoubunrui)
           if sc.hachu_saibunrui:
               parts.append(sc.hachu_saibunrui)
       
       # 工事名はFileInfoのmetadataから取得
       koji_name = None
       if file_info.metadata and "koji_name" in file_info.metadata:
           koji_name = file_info.metadata["koji_name"]
       
       if koji_name:
           parts.append(koji_name)
       
       if not parts:
           return "その他"
       
       folder_name = "_".join(parts)
       folder_name = self.file_utils.sanitize_filename(folder_name)
       
       if not folder_name:
           return "その他"
       
       return folder_name
   ```

## 問題2: GUIで「工事場所（リスト検索）」の「地方」に「北海道」が初期選択されている

### 現状の問題

GUIを起動すると、「工事場所（リスト検索）」の「地方」ドロップダウンに「北海道」が選択されている。

### 現状の実装

1. **`main_window.py`**:
   - 275行目: `place_chihou_options = ["", "北海道", "東北", ...]`（最初の要素は空文字列）
   - 277行目: `self.place_chihou_var = tk.StringVar(value=search_conditions.place_chihou)`
   - 793行目: `self.place_chihou_var.set(search_conditions.place_chihou)`（`load_config_to_ui()`で）

2. **`config_model.py`**:
   - `SearchConditions.place_chihou: str = ""`（デフォルト値は空文字列）

### 原因の推測

1. **`load_config_to_ui()`で設定を読み込む際に、デフォルト値が設定されている可能性**
   - `config.yaml`に`place_chihou: "北海道"`が設定されている可能性
   - または、`ConfigManager`でデフォルト値が設定されている可能性

2. **`StringVar`の初期値設定の問題**
   - `tk.StringVar(value="")`の場合、Comboboxの最初の要素（空文字列）が選択されるはず
   - しかし、何らかの理由で「北海道」が選択されている

### 修正案

#### 方針1: 初期値を明示的に空文字列に設定

1. **`main_window.py`の修正**:
   ```python
   # 277行目を修正
   self.place_chihou_var = tk.StringVar(value="")  # 明示的に空文字列を設定
   
   # または、search_conditions.place_chihouが空文字列でない場合のみ設定
   initial_value = search_conditions.place_chihou if search_conditions.place_chihou else ""
   self.place_chihou_var = tk.StringVar(value=initial_value)
   ```

2. **`load_config_to_ui()`の修正**:
   ```python
   # 793行目を修正
   # 空文字列の場合は明示的に空文字列を設定
   place_chihou_value = search_conditions.place_chihou if search_conditions.place_chihou else ""
   self.place_chihou_var.set(place_chihou_value)
   ```

#### 方針2: 設定ファイルの確認と修正

1. **`config.yaml`の確認**:
   - `place_chihou: "北海道"`が設定されていないか確認
   - 設定されている場合は削除または空文字列に変更

2. **`ConfigManager`の確認**:
   - デフォルト値が設定されていないか確認

### 推奨される修正

**方針1を採用**し、以下の修正を行う：

1. **`main_window.py`の277行目を修正**:
   ```python
   # 修正前
   self.place_chihou_var = tk.StringVar(value=search_conditions.place_chihou)
   
   # 修正後
   initial_value = search_conditions.place_chihou if search_conditions.place_chihou else ""
   self.place_chihou_var = tk.StringVar(value=initial_value)
   ```

2. **`main_window.py`の793行目を修正**:
   ```python
   # 修正前
   self.place_chihou_var.set(search_conditions.place_chihou)
   
   # 修正後
   place_chihou_value = search_conditions.place_chihou if search_conditions.place_chihou else ""
   self.place_chihou_var.set(place_chihou_value)
   ```
