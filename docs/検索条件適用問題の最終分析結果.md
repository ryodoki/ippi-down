# 検索条件適用問題の最終分析結果

**分析日**: 2026年1月13日

---

## 問題の原因（確定）

### 1. 階層的ドロップダウンの問題

**現状**:
- 検索条件で「東北地方整備局」を指定しているのに、検索結果に「関東地方整備局」の案件が含まれている
- 中分類のPOSTバック後に小分類の選択肢が読み込まれていない

**原因**:
- 小分類の選択肢はJavaScriptで動的に読み込まれる
- `createListItem2()`や`createListItem1_3()`関数が`Common.js`から読み込まれ、`txtLargeKikanInf_h`から小分類の選択肢を取得している
- しかし、これらの関数はブラウザ側で実行されるため、`requests`ライブラリだけでは対応できない

### 2. HARファイルとの比較

**HARファイルの確認結果**:
- 小分類のPOSTバック時に`drpMiddleKikanInf: '02'`が設定されている
- これは、中分類のPOSTバック後に小分類の選択肢が読み込まれ、その中から「東北地方整備局」を選択したことを示している

**現在の実装との違い**:
- 中分類のPOSTバック後に小分類の選択肢が読み込まれていない
- `txtLgKikanInf2SelIndex_h`が空文字列（HARファイルでは'4'が設定されている）

---

## 対応方針

### 方針1: JavaScriptの実行を模倣（推奨）

`createListItem2()`や`createListItem1_3()`のロジックをPythonで実装し、`txtLargeKikanInf_h`から小分類の選択肢を取得する。

**実装内容**:
1. `txtLargeKikanInf_h`から中分類の値に一致する小分類の選択肢を抽出（既に実装済み）
2. 中分類のPOSTバック後に、抽出した小分類の選択肢から値を取得
3. 小分類の値を設定して検索を実行

**メリット**:
- 検索条件が正しく適用される
- サーバー側の検索機能を活用できる

**デメリット**:
- JavaScriptのロジックを正確に再現する必要がある
- `Common.js`が取得できないため、ロジックを推測する必要がある

### 方針2: 検索結果ページでフィルタリング（確実）

検索結果ページから取得したファイルが、検索条件に一致しているか確認し、一致しない場合は除外する。

**実装内容**:
1. 検索結果ページから各案件の情報（発注機関、工事名、工事場所など）を抽出
2. 検索条件と照合
3. 一致しない案件のファイルを除外

**メリット**:
- 確実に動作する
- JavaScriptの実行を模倣する必要がない

**デメリット**:
- サーバー側で不要なファイルも取得される（効率が悪い）
- 検索結果ページの解析が必要

---

## 推奨される対応

**方針1を優先的に実装し、方針2をフォールバックとして実装する**

1. **まず方針1を実装**
   - `txtLargeKikanInf_h`から小分類の選択肢を取得（既に実装済み）
   - 中分類のPOSTバック後に、抽出した小分類の選択肢から値を取得
   - 小分類の値を設定して検索を実行

2. **方針1が動作しない場合、方針2を実装**
   - 検索結果ページから各案件の情報を抽出
   - 検索条件と照合してフィルタリング

## 実装の詳細

### 方針1の実装

```python
def submit_search_form_with_hierarchy(
    self, 
    search_url: str, 
    search_conditions: SearchConditions
) -> Optional[BeautifulSoup]:
    """階層的ドロップダウンを考慮した検索フォーム送信"""
    normalized_url = self._normalize_search_url(search_url)
    
    # 1. 初期ページを取得
    soup = self.fetch_page(normalized_url)
    if not soup:
        return None
    
    # 2. 大分類を選択してPOSTバック
    form_data = self._get_all_hidden_inputs(soup)
    form_data["__EVENTTARGET"] = "drpTopKikanInf"
    form_data["__EVENTARGUMENT"] = ""
    form_data["drpTopKikanInf"] = self._get_dropdown_value_from_text(soup, "drpTopKikanInf", search_conditions.hachu_daibunrui)
    
    response = self.http_client.post(normalized_url, data=form_data)
    soup = BeautifulSoup(response.content, "lxml")
    
    # 3. 中分類を選択してPOSTバック
    form_data = self._get_all_hidden_inputs(soup)
    form_data["__EVENTTARGET"] = "drpLargeKikanInf2"
    form_data["__EVENTARGUMENT"] = ""
    form_data["drpTopKikanInf"] = self._get_dropdown_value_from_text(soup, "drpTopKikanInf", search_conditions.hachu_daibunrui)
    chubunrui_value = self._get_dropdown_value_from_text(soup, "drpLargeKikanInf2", search_conditions.hachu_chubunrui)
    form_data["drpLargeKikanInf2"] = chubunrui_value
    
    # txtLgKikanInf2SelIndex_hを設定
    dropdown = soup.find("select", id="drpLargeKikanInf2")
    if dropdown:
        options = dropdown.find_all("option")
        for idx, opt in enumerate(options):
            if opt.get("value", "") == chubunrui_value:
                form_data["txtLgKikanInf2SelIndex_h"] = str(idx)
                break
    
    response = self.http_client.post(normalized_url, data=form_data)
    soup = BeautifulSoup(response.content, "lxml")
    
    # 4. txtLargeKikanInf_hから小分類の選択肢を取得
    form_data = self._get_all_hidden_inputs(soup)
    if "txtLargeKikanInf_h" in form_data:
        shoubunrui_options = self._parse_txtLargeKikanInf_h(form_data["txtLargeKikanInf_h"], chubunrui_value)
        
        # 小分類の値を取得
        shoubunrui_value = None
        for value, text in shoubunrui_options:
            if search_conditions.hachu_shoubunrui in text:
                shoubunrui_value = value
                break
        
        if shoubunrui_value:
            # 小分類の値を設定して検索を実行
            form_data["drpMiddleKikanInf"] = shoubunrui_value
    
    # 5. 検索を実行
    search_form_data = self._build_search_form_data(search_conditions, soup)
    form_data.update(search_form_data)
    
    response = self.http_client.post(normalized_url, data=form_data)
    soup = BeautifulSoup(response.content, "lxml")
    
    return soup
```

```python
def filter_search_results_by_conditions(
    self,
    file_list: List[FileInfo],
    search_conditions: SearchConditions
) -> List[FileInfo]:
    """検索結果を検索条件でフィルタリング"""
    filtered_files = []
    
    for file_info in file_list:
        is_matched = True
        
        # 発注機関の照合
        if search_conditions.hachu_shoubunrui:
            hachu_kikan = file_info.metadata.get("hachu_kikan", "")
            if search_conditions.hachu_shoubunrui not in hachu_kikan:
                is_matched = False
        
        # 工事場所の照合
        if search_conditions.place_todofuken:
            place = file_info.metadata.get("place", "")
            if search_conditions.place_todofuken not in place:
                is_matched = False
        
        if is_matched:
            filtered_files.append(file_info)
    
    return filtered_files
```
