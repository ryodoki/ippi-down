# 検索条件適用問題の原因と対応方針

**分析日**: 2026年1月13日

---

## 問題の原因

### 1. 階層的ドロップダウンの問題

**現状**:
- 検索条件で「東北地方整備局」を指定しているのに、検索結果に「関東地方整備局」の案件が含まれている
- 特に「横浜営繕事務所」の案件も含まれている

**原因**:
- ASP.NET WebFormsの階層的ドロップダウンは、親の選択が変更されると、JavaScriptで子の選択肢が動的に読み込まれる
- 最初のページ読み込み時には、中分類・小分類・細分類の選択肢は空（またはデフォルト値のみ）になっている
- 現在の実装では、大分類を選択した後、中分類・小分類・細分類の選択肢を取得していない

**確認結果**:
```
大分類: '国の機関' -> 値 '0' (正しく取得)
中分類: '国土交通省' -> 値 'None' (取得失敗)
小分類: '東北地方整備局' -> 値 'None' (取得失敗)
```

### 2. 検索フォームの送信データ

**現状**:
- `drpTopKikanInf`: '0' (大分類のみ設定)
- `drpLargeKikanInf2`: (設定されていない)
- `drpMiddleKikanInf`: (設定されていない)
- `drpSmallKikanInf`: (設定されていない)

**結果**:
- 大分類のみで検索されるため、すべての「国の機関」の案件が検索結果に含まれる
- 中分類・小分類のフィルタリングが機能していない

---

## 対応方針

### 1. 階層的ドロップダウンの値を取得する処理を実装

#### 1.1 POSTバックを順次実行

階層的なドロップダウンの値を取得するために、以下の手順を実行する必要があります：

1. **大分類を選択**
   - `drpTopKikanInf` に値を設定
   - POSTバックを実行（`__EVENTTARGET` = `drpTopKikanInf`）
   - 中分類の選択肢を取得

2. **中分類を選択**
   - `drpLargeKikanInf2` に値を設定
   - POSTバックを実行（`__EVENTTARGET` = `drpLargeKikanInf2`）
   - 小分類の選択肢を取得

3. **小分類を選択**
   - `drpMiddleKikanInf` に値を設定
   - POSTバックを実行（`__EVENTTARGET` = `drpMiddleKikanInf`）
   - 細分類の選択肢を取得

4. **細分類を選択**（必要な場合）
   - `drpSmallKikanInf` に値を設定

5. **検索を実行**
   - すべての検索条件を設定
   - 検索ボタンをクリック（POSTバック）

#### 1.2 実装方法

`Scraper`クラスに以下のメソッドを追加：

```python
def _get_dropdown_value_with_postback(
    self, 
    soup: BeautifulSoup, 
    select_id: str, 
    target_text: str,
    base_url: str
) -> Tuple[Optional[str], BeautifulSoup]:
    """ドロップダウンの値を取得（POSTバックを実行）"""
    # 1. 現在の選択肢から値を取得
    value = self._get_dropdown_value_from_text(soup, select_id, target_text)
    if value:
        return value, soup
    
    # 2. POSTバックを実行して選択肢を更新
    form_data = self._get_all_hidden_inputs(soup)
    form_data["__EVENTTARGET"] = select_id
    form_data["__EVENTARGUMENT"] = ""
    
    response = self.http_client.post(base_url, data=form_data)
    new_soup = BeautifulSoup(response.content, "lxml")
    
    # 3. 更新後の選択肢から値を取得
    value = self._get_dropdown_value_from_text(new_soup, select_id, target_text)
    return value, new_soup

def submit_search_form_with_hierarchy(
    self, 
    search_url: str, 
    search_conditions: SearchConditions
) -> Optional[BeautifulSoup]:
    """階層的ドロップダウンを考慮した検索フォーム送信"""
    normalized_url = self._normalize_search_url(search_url)
    
    # 初期ページを取得
    soup = self.fetch_page(normalized_url)
    if not soup:
        return None
    
    # 大分類を選択
    if search_conditions.hachu_daibunrui:
        value, soup = self._get_dropdown_value_with_postback(
            soup, "drpTopKikanInf", search_conditions.hachu_daibunrui, normalized_url
        )
        if not value:
            self.logger.warning(f"大分類 '{search_conditions.hachu_daibunrui}' の値が取得できませんでした")
    
    # 中分類を選択
    if search_conditions.hachu_chubunrui:
        value, soup = self._get_dropdown_value_with_postback(
            soup, "drpLargeKikanInf2", search_conditions.hachu_chubunrui, normalized_url
        )
        if not value:
            self.logger.warning(f"中分類 '{search_conditions.hachu_chubunrui}' の値が取得できませんでした")
    
    # 小分類を選択
    if search_conditions.hachu_shoubunrui:
        value, soup = self._get_dropdown_value_with_postback(
            soup, "drpMiddleKikanInf", search_conditions.hachu_shoubunrui, normalized_url
        )
        if not value:
            self.logger.warning(f"小分類 '{search_conditions.hachu_shoubunrui}' の値が取得できませんでした")
    
    # 細分類を選択
    if search_conditions.hachu_saibunrui:
        value, soup = self._get_dropdown_value_with_postback(
            soup, "drpSmallKikanInf", search_conditions.hachu_saibunrui, normalized_url
        )
        if not value:
            self.logger.warning(f"細分類 '{search_conditions.hachu_saibunrui}' の値が取得できませんでした")
    
    # 検索フォームのデータを構築
    form_data = self._get_all_hidden_inputs(soup)
    search_form_data = self._build_search_form_data(search_conditions, soup)
    form_data.update(search_form_data)
    
    # 検索を実行
    response = self.http_client.post(normalized_url, data=form_data)
    soup = BeautifulSoup(response.content, "lxml")
    
    return soup
```

### 2. 検索結果のフィルタリング

検索結果ページから取得したファイルが、検索条件に一致しているか確認し、一致しない場合は除外する。

## 実装の優先順位

1. **最優先**: 階層的ドロップダウンの値を取得する処理を実装
2. **次**: 検索結果のフィルタリング処理を実装
3. **最後**: 工事名ごとのフォルダ分け処理を実装

## テスト方法

1. 検索条件を設定（大分類、中分類、小分類）
2. 検索を実行
3. 検索結果を確認
   - 指定した小分類（例: 東北地方整備局）の案件のみが含まれているか
   - 他の分類（例: 関東地方整備局）の案件が含まれていないか
