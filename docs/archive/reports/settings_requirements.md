# 設定機能 詳細要件定義書

## 1. 現状と問題点

### 1.1 現状
- **設定機能が未実装**: `main_window.py`の`on_settings_open`メソッドで「設定機能は今後実装予定です」というメッセージを表示しているのみ
- **設定ファイルの読み込み/保存機能は実装済み**: `ConfigManager`クラスは実装されている
- **GUI設定画面が未実装**: `SettingsDialog`クラスが設計されているが実装されていない

### 1.2 問題点
- ユーザーがGUIから設定を変更できない
- 設定ファイルを直接編集する必要がある（技術的知識が必要）
- 設定の検証がGUI上でできない
- 設定の保存/読み込みがGUIからできない

## 2. 機能要件

### 2.1 基本機能要件

#### FR-SET-001: 設定ダイアログの表示
- **要件**: 「設定」ボタンをクリックすると設定ダイアログが表示されること
- **優先度**: 高
- **詳細**:
  - モーダルダイアログとして表示
  - 親ウィンドウ（メインウィンドウ）の中央に表示
  - ダイアログサイズ: 幅600px、高さ700px（スクロール可能）

#### FR-SET-002: 設定項目の表示
- **要件**: すべての設定項目をGUI上で表示・編集できること
- **優先度**: 高
- **詳細**: 以下の設定項目を含む
  1. **対象URL設定**
     - 複数のURLを追加/削除/編集できる
     - URL入力欄と「追加」「削除」ボタン
     - URLリストの表示（リストボックスまたはテーブル）
  
  2. **ダウンロード条件設定**
     - ファイルタイプ選択（チェックボックス）
       - PDF、Excel、Word、画像、その他
     - キーワード入力（複数入力可能）
       - キーワード入力欄と「追加」「削除」ボタン
       - キーワードリストの表示
     - 日付範囲設定
       - 開始日（カレンダーまたは日付入力）
       - 終了日（カレンダーまたは日付入力）
       - 「日付範囲をクリア」ボタン
  
  3. **保存先設定**
     - ローカル保存先
       - パス入力欄
       - 「参照」ボタン（フォルダ選択ダイアログ）
     - 発注機関ごとのルートフォルダ（オプション、実装済み）
       - 「発注機関ごとにルートフォルダを作成」チェックボックス
       - 「工事/業務でフォルダを分ける」チェックボックス
       - 日付フォルダ分割（なし/年/年_月/年_月_日）のプルダウン
       - 詳細は README の「発注機関ごとのルートフォルダ」と `config.example.yaml` を参照
  4. **ファイル命名規則設定**
     - 命名規則入力欄
     - 使用可能な変数の説明表示
     - プレビュー表示（例: `{category}_{title}_{date}_{index}.pdf`）
  
  5. **スケジュール設定**
     - スケジュール有効化チェックボックス
     - 実行間隔選択（プルダウン: 1日、1週間、1か月）
     - 実行時間入力（HH:MM形式）
     - 次回実行予定時刻の表示
  
  6. **ログ設定**
     - ログレベル選択（プルダウン: DEBUG、INFO、WARNING、ERROR）
     - ログファイルパス入力欄
     - 「参照」ボタン（ファイル選択ダイアログ）
     - 最大ファイルサイズ入力（MB単位）
     - バックアップファイル数入力

#### FR-SET-003: 設定値の検証
- **要件**: 設定値を保存する前に検証を行うこと
- **優先度**: 高
- **詳細**:
  - URLの形式チェック
  - ファイルパスの存在確認（存在しない場合は作成確認）
  - 日付範囲の妥当性チェック（開始日 < 終了日）
  - 必須項目の入力チェック
  - エラーがある場合はエラーメッセージを表示し、該当項目をハイライト

#### FR-SET-004: 設定の保存
- **要件**: 「保存」ボタンで設定をファイルに保存できること
- **優先度**: 高
- **詳細**:
  - 設定値を検証してから保存
  - 保存成功時に「設定を保存しました」というメッセージを表示
  - 保存失敗時はエラーメッセージを表示
  - 保存後、メインウィンドウの設定を更新

#### FR-SET-005: 設定の読み込み
- **要件**: ダイアログを開いたときに現在の設定を読み込んで表示すること
- **優先度**: 高
- **詳細**:
  - 設定ファイルから設定を読み込む
  - 各設定項目に現在の値を設定
  - 設定ファイルが存在しない場合はデフォルト値を表示

#### FR-SET-006: 設定のキャンセル
- **要件**: 「キャンセル」ボタンで変更を破棄してダイアログを閉じること
- **優先度**: 中
- **詳細**:
  - 変更を保存せずにダイアログを閉じる
  - 未保存の変更がある場合は確認ダイアログを表示

#### FR-SET-007: 設定のリセット
- **要件**: 「デフォルトに戻す」ボタンで設定をデフォルト値にリセットできること
- **優先度**: 低
- **詳細**:
  - すべての設定項目をデフォルト値にリセット
  - リセット前に確認ダイアログを表示

### 2.2 高度な機能要件

#### FR-SET-008: 設定プロファイル管理
- **要件**: 複数の設定プロファイルを保存・読み込みできること
- **優先度**: 中
- **詳細**:
  - プロファイル名の入力
  - プロファイルの保存（別ファイルとして保存）
  - プロファイルの読み込み（プルダウンから選択）
  - プロファイルの削除
  - 現在のプロファイル名の表示

#### FR-SET-009: 設定のインポート/エクスポート
- **要件**: 設定ファイルをインポート/エクスポートできること
- **優先度**: 低
- **詳細**:
  - 設定をYAMLファイルとしてエクスポート
  - 設定ファイルをインポート
  - インポート時に既存設定とのマージオプション

#### FR-SET-010: 設定のプレビュー
- **要件**: 設定変更の影響をプレビューできること
- **優先度**: 低
- **詳細**:
  - 命名規則のプレビュー
  - 保存先パスのプレビュー
  - 次回実行予定時刻の表示

## 4. データフロー

### 4.1 設定ダイアログを開く
```
[ユーザー: 設定ボタンをクリック]
    │
    ▼
[MainWindow: on_settings_open()呼び出し]
    │
    ▼
[ConfigManager: 設定ファイルを読み込み]
    │
    ▼
[SettingsDialog: 作成・表示]
    │
    ▼
[SettingsDialog: 現在の設定値をUIに反映]
```

### 4.2 設定を保存
```
[ユーザー: 保存ボタンをクリック]
    │
    ▼
[SettingsDialog: UIから設定値を取得]
    │
    ▼
[ConfigValidator: 設定値を検証]
    │
    ├─ エラーあり → [エラーメッセージ表示] → 終了
    │
    └─ エラーなし
        │
        ▼
[ConfigManager: 設定ファイルに保存]
    │
    ├─ 保存失敗 → [エラーメッセージ表示]
    │
    └─ 保存成功
        │
        ▼
[MainWindow: 設定を更新]
    │
    ▼
[SettingsDialog: 保存完了メッセージ表示]
    │
    ▼
[SettingsDialog: ダイアログを閉じる]
```

## 5. エラーハンドリング

### 5.1 検証エラー
- **URL形式エラー**: 「無効なURL形式です」と表示し、該当URLをハイライト
- **パスエラー**: 「パスが無効です」と表示し、参照ボタンを強調
- **日付範囲エラー**: 「開始日が終了日より後です」と表示
- **必須項目エラー**: 「必須項目が入力されていません」と表示し、該当項目をハイライト

### 5.2 保存エラー
- **ファイル書き込みエラー**: 「設定ファイルの保存に失敗しました」と表示
- **権限エラー**: 「設定ファイルへの書き込み権限がありません」と表示

## 6. 実装優先度

### 高優先度（必須）
1. FR-SET-001: 設定ダイアログの表示
2. FR-SET-002: 設定項目の表示（基本設定のみ）
3. FR-SET-003: 設定値の検証
4. FR-SET-004: 設定の保存
5. FR-SET-005: 設定の読み込み
6. FR-SET-006: 設定のキャンセル

### 中優先度（推奨）
7. FR-SET-007: 設定のリセット
8. FR-SET-008: 設定プロファイル管理

### 低優先度（将来実装）
9. FR-SET-009: 設定のインポート/エクスポート
10. FR-SET-010: 設定のプレビュー
