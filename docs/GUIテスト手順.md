# GUIテスト手順

**テスト日**: 2026年1月14日

---

## テスト項目

### 1. 階層的ドロップダウンの動作確認

#### テスト手順

1. **GUIを起動**
   - `python src/main.py` を実行
   - GUIウィンドウが表示されることを確認

2. **大分類を選択**
   - 「発注機関（リスト検索）」の「大分類」ドロップダウンを開く
   - 「国の機関」を選択
   - 中分類のドロップダウンに選択肢が表示されることを確認

3. **中分類を選択**
   - 「中分類」ドロップダウンを開く
   - 「国土交通省」を選択
   - 小分類のドロップダウンに選択肢が表示されることを確認

4. **小分類を選択**
   - 「小分類」ドロップダウンを開く
   - 「東北地方整備局」を選択
   - 細分類のドロップダウンに選択肢が表示されることを確認

5. **細分類を選択（オプション）**
   - 「細分類」ドロップダウンを開く
   - 任意の細分類を選択（例: 「総務部」）
   - 選択肢が表示されることを確認

### 2. 検索条件の適用確認

#### テスト手順

1. **検索条件を設定**
   - 大分類: 国の機関
   - 中分類: 国土交通省
   - 小分類: 東北地方整備局
   - 細分類: （任意、例: 総務部）

2. **ダウンロードを実行**
   - 「ダウンロード開始」ボタンをクリック
   - ログウィンドウで進行状況を確認

3. **検索結果の確認**
   - ダウンロードされたファイルを確認
   - 検索条件に一致する案件のみがダウンロードされていることを確認
   - フォルダ名が正しく生成されていることを確認（例: `国の機関_国土交通省_東北地方整備局_総務部`）

### 3. ファイル名とフォルダ構造の確認

#### テスト手順

1. **ダウンロード完了後**
   - 保存先フォルダを確認
   - フォルダ名が検索条件に基づいて生成されていることを確認

2. **ファイル名の確認**
   - ダウンロードされたファイルの名前を確認
   - ファイル名が検索条件を含んでいることを確認（例: `国の機関_国土交通省_東北地方整備局_総務部_工事名_ファイル名.pdf`）

## 期待される動作

### 正常な動作

1. **階層的ドロップダウンの連動**
   - 大分類を選択すると、中分類の選択肢が更新される
   - 中分類を選択すると、小分類の選択肢が更新される
   - 小分類を選択すると、細分類の選択肢が更新される

2. **検索条件の適用**
   - 設定した検索条件に一致する案件のみがダウンロードされる
   - 検索条件に一致しない案件はダウンロードされない

3. **ファイル名とフォルダ構造**
   - フォルダ名が検索条件に基づいて生成される
   - ファイル名が検索条件を含む

### エラーケース

1. **ドロップダウンが更新されない**
   - ログを確認してエラーメッセージを確認
   - ネットワーク接続を確認

2. **検索結果が正しくない**
   - ログを確認して検索条件が正しく設定されているか確認
   - 検索条件の適用を確認

## ログの確認方法

ログファイル: `logs/app.log`

主要なログメッセージ:
- `大分類を選択: '国の機関' -> '0'`
- `中分類を選択: '国土交通省' -> '21'`
- `小分類を選択: '東北地方整備局' -> '02'`
- `細分類を選択: '総務部' -> '001'`
- `検索結果ページを取得しました`
- `保存先フォルダ名: '国の機関_国土交通省_東北地方整備局_総務部'`

## トラブルシューティング

### GUIが表示されない

- Pythonのバージョンを確認（3.11.x推奨）
- tkinterがインストールされているか確認
- エラーメッセージを確認

### ドロップダウンが更新されない

- ネットワーク接続を確認
- ログファイルでエラーメッセージを確認
- ブラウザで直接アクセスして動作を確認

### 検索結果が正しくない

- 検索条件が正しく設定されているか確認
- ログファイルで検索条件を確認
- 検索結果ページのHTMLを確認
