# 最小限ダウンロード機能の動作確認手順

**目的**: 要件定義書に基づいた修正を進める前に、現在のコードで最小限のダウンロードが動作するかを確認します。

---

## 確認項目

### ✅ 確認すべき基本機能

1. **ページ取得**: 検索画面のHTMLを取得できるか
2. **ファイルリンク抽出**: ページからファイルリンクを抽出できるか
3. **フィルタリング**: ファイルタイプでフィルタリングできるか
4. **ダウンロード実行**: 実際にファイルをダウンロードできるか
5. **エラーハンドリング**: エラーが発生した場合に適切に処理されるか

---

## 確認すべきポイント

### 1. ページ取得が成功するか

**確認項目**:
- HTTPリクエストが成功するか（200 OK）
- HTMLが正しく取得できるか
- エンコーディングが正しく処理されるか

**問題が発生した場合**:
- ネットワーク接続を確認
- タイムアウト設定を確認（現在は固定値30秒）
- User-Agentを確認（現在はMozilla/5.0...）

---

### 2. ファイルリンクの抽出ができるか

**確認項目**:
- 検索結果ページからファイルリンクを抽出できるか
- 詳細ページへの遷移が必要な場合、正しく処理できるか
- `dgrKokoku`、`dgrKeika`テーブルからリンクを抽出できるか

**問題が発生した場合**:
- サイト構造が変更されていないか確認
- 詳細ページへの遷移処理を確認
- `__doPostBack`処理が正しく動作するか確認

---

### 3. ダウンロードが実行できるか

**確認項目**:
- ファイルURLにアクセスできるか
- ファイルが正しく保存されるか
- ファイル名が正しく生成されるか
- 進捗コールバックが動作するか

**問題が発生した場合**:
- ファイルURLが有効か確認
- 保存先ディレクトリの権限を確認
- タイムアウト設定を確認（現在は固定値60秒）

---

### 4. エラーハンドリングが機能するか

**確認項目**:
- ネットワークエラー時に適切にエラーを記録するか
- タイムアウト時に適切に処理されるか
- ファイル保存エラー時に適切に処理されるか

**問題が発生した場合**:
- エラーメッセージが適切か確認
- ログに記録されているか確認
- 処理が継続できるか確認

---

### ❌ 失敗パターンと対処

#### パターン1: ページ取得に失敗
```
❌ ページ取得に失敗しました
```
**対処**: 
- ネットワーク接続を確認
- サイトが利用可能か確認
- タイムアウト設定を確認

#### パターン2: ファイルリンクが見つからない
```
⚠ ファイルリンクが見つかりませんでした
```
**対処**:
- 検索条件を指定して検索フォームを送信する必要がある可能性
- 詳細ページへの遷移処理を確認
- サイト構造の変更を確認

#### パターン3: ダウンロードに失敗
```
❌ ダウンロードに失敗しました
  エラー: Connection timeout
```
**対処**:
- ファイルURLが有効か確認
- タイムアウト設定を確認（要件定義では10秒/60秒）
- リトライ機能を確認

## 次のステップ

### テストが成功した場合

1. **要件定義書に基づいた修正を開始**
   - Phase 1: 基盤整備（ConfigModel、HTTPClient等）
   - Phase 2: コア機能実装（.partファイル、キャンセル機能等）
   - Phase 3: ログ・エラーハンドリング

2. **既存機能を維持しながら修正**
   - 動作している機能を壊さないように注意
   - 段階的に修正を進める

### テストが失敗した場合

1. **問題の特定**
   - どの段階で失敗しているか確認
   - エラーメッセージを確認
   - ログを確認

2. **基本機能の修正を優先**
   - ページ取得が失敗する場合: HTTPClientの修正
   - ファイルリンク抽出が失敗する場合: Scraperの修正
   - ダウンロードが失敗する場合: Downloaderの修正

3. **修正後に再テスト**
   - 同じテストスクリプトで再確認
   - 成功するまで繰り返す

---

## 注意事項

- **テスト実行時は実際のサイトにアクセスします**
- **レート制限に注意してください**（要件定義では1〜2 req/sec）
- **テストファイルは `downloads/test_minimal/` に保存されます**
- **テスト後は不要なファイルを削除してください**
