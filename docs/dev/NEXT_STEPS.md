## 🛠️ 推奨される開発フロー

1. **ローカルでの開発**
   ```bash
   # 機能追加・修正
   git checkout -b feature/機能名
   # コードを書く
   git add .
   git commit -m "feat: 機能を追加"
   ```

2. **テストの実行**
   ```bash
   pytest tests/ -v
   python test_minimal_download.py
   ```

3. **コミット前の確認**
   ```bash
   git status
   git diff
   ```

4. **コミットとプッシュ**（リモートが設定されている場合）
   ```bash
   git commit -m "feat: 機能を追加"
   git push origin feature/機能名
   ```
