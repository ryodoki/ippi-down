## 問題が続く場合

### ログを確認

1. `logs/app.log`の最新のログを確認
2. 以下のログが出力されているか確認:
   - `検索条件 - 大分類: '...', ...`
   - `保存先フォルダ名: '...'`
   - `生成されたフォルダ名: '...'`
   - `生成されたファイル名: '...'`

### 考えられる原因

1. **検索条件が空の場合**
   - ログに`検索条件 - 大分類: '', 中分類: '', ...`と表示される
   - → GUIで検索条件を正しく設定してください

2. **検索条件が取得できていない場合**
   - ログに`検索条件が設定されていません`と表示される
   - → `get_config_from_ui()`メソッドの問題の可能性

3. **フォルダ名が空の場合**
   - ログに`フォルダ名が空のため、デフォルトフォルダ名 'その他' を使用します`と表示される
   - → 検索条件の値がすべて空の可能性
