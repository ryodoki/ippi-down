## 実装内容

### 1. 階層的ドロップダウンのPOSTバックを順次実行

- 大分類 → 中分類 → 小分類の順にPOSTバックを実行
- 各POSTバック後にレスポンスを取得し、次のドロップダウンの選択肢を読み込む

### 2. ブラウザと同様のパラメータを設定

以下のパラメータをブラウザと同様に設定：

- `txtLgKikanInfSelValue_h`: 中分類のテキスト + "," + 中分類のvalue（例: `'国土交通省,21'`）
- `txtLgKikanInf2SelIndex_h`: 中分類の選択インデックス
- `txt_ChangeTopKikan`: 大分類が変更された場合は`'true'`
- `txt_ChangeLargeKikan`: 中分類が変更された場合は`'true'`
- `drpMiddleKikanInf`: 小分類のドロップダウンに`'-1'`を設定（POSTバック時）

### 3. POSTバック後のHTMLから小分類の選択肢を取得

- POSTバック後のレスポンスHTMLから`<select id="drpMiddleKikanInf">`を解析
- 小分類の選択肢を取得し、検索条件に一致する値を設定

## 修正内容

### 修正前の問題

1. **`txtLgKikanInfSelValue_h`が空文字列**
   - ブラウザでは`'国土交通省,21'`が設定されているが、`requests`では空文字列

2. **`txt_ChangeTopKikan`が`'false'`**
   - ブラウザでは`'true'`が設定されているが、`requests`では`'false'`

3. **`drpMiddleKikanInf`が設定されていない**
   - ブラウザでは`'-1'`が設定されているが、`requests`では設定されていない

4. **小分類の選択肢が取得できない**
   - `txtLargeKikanInf_h`から小分類の選択肢を取得しようとしていたが、POSTバック後のHTMLに含まれている

### 修正後の実装

1. **`txtLgKikanInfSelValue_h`を正しく設定**
   ```python
   form_data["txtLgKikanInfSelValue_h"] = f"{chubunrui_text},{chubunrui_value}"
   ```

2. **`txt_ChangeTopKikan`と`txt_ChangeLargeKikan`を正しく設定**
   ```python
   form_data["txt_ChangeTopKikan"] = "true" if daibunrui_value else "false"
   form_data["txt_ChangeLargeKikan"] = "true"
   ```

3. **`drpMiddleKikanInf`を設定**
   ```python
   form_data["drpMiddleKikanInf"] = "-1"
   ```

4. **POSTバック後のHTMLから小分類の選択肢を取得**
   ```python
   dropdown = soup.find("select", id="drpMiddleKikanInf")
   if dropdown:
       options = dropdown.find_all("option")
       for opt in options:
           value = opt.get("value", "")
           text = opt.get_text(strip=True)
           if value != "-1" and search_conditions.hachu_shoubunrui in text:
               shoubunrui_value = value
               break
   ```
