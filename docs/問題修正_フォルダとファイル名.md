# 問題修正: フォルダとファイル名

**修正日**: 2026年1月13日  
**問題**: 
1. フォルダが作成されていない
2. ファイル名が指定した通りになっていない

---

## 問題の原因

### 1. フォルダが作成されていない

**原因**:
- `download_files`関数（GUI版）で`downloader.download_files`を呼び出す際に、`folder_name`パラメータを渡していなかった
- フォルダ名は生成されていたが、`Downloader`に渡されていなかった

### 2. ファイル名が指定した通りになっていない

**原因**:
- `download_files`関数（GUI版）で`Naming`を初期化する際に、検索条件を渡していなかった
- 検索条件が`None`のため、フォルダ名とファイル名が「その他」や元のファイル名のままになっていた

---

## 修正内容

### 1. `download_files`関数の修正

**ファイル**: `src/main.py`

#### 修正前
```python
# 初期化
naming = Naming(config.naming_rule, logger)  # 検索条件を渡していない

# ...

result = downloader.download_files(
    filtered_files,
    config.save_paths.local,
    naming,
    progress_callback,
    # folder_nameを渡していない
)
```

#### 修正後
```python
# デバッグ: 検索条件を確認
if config.search_conditions:
    sc = config.search_conditions
    logger.info(f"検索条件 - 大分類: '{sc.hachu_daibunrui}', 中分類: '{sc.hachu_chubunrui}', 小分類: '{sc.hachu_shoubunrui}', 細分類: '{sc.hachu_saibunrui}', 工事名: '{sc.koji_name}'")
else:
    logger.warning("検索条件が設定されていません")

# Namingを初期化（検索条件を渡す）
naming = Naming(config.naming_rule, logger, config.search_conditions)

# ...

# フォルダ名を生成
folder_name = naming.generate_folder_name()
logger.info(f"保存先フォルダ名: '{folder_name}'")

result = downloader.download_files(
    filtered_files,
    config.save_paths.local,
    naming,
    progress_callback,
    folder_name=folder_name,  # フォルダ名を渡す
)
```

### 2. デバッグログの追加

**ファイル**: `src/core/naming.py`

- `generate_folder_name()`メソッドにデバッグログを追加
- `generate_filename()`メソッドにデバッグログを追加
- 検索条件が設定されていない場合の警告を追加
