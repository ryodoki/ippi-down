# 設定画面の現行仕様

この文書は現在の`SettingsDialog`と定期実行編集画面の動作を記録する。全体の機能要件は[要件定義](requirements.md)、利用者向けの操作説明は[README](../README.md)を参照する。

## 画面構成

メイン画面の「設定」、または「定期実行設定」からモーダルの設定画面を開く。後者は定期実行タブを選んで開く。設定画面には「基本設定」「定期実行」「詳細設定」の3タブがある。初期サイズは作業領域に合わせて縮め、最小サイズも作業領域を超えないようにする。

保存・キャンセル・デフォルトに戻すボタンはタブ外のフッターに置く。定期実行の操作欄もタブ上部に固定し、幅が足りない場合は複数行に折り返す。基本設定と定期実行の本文は縦スクロールできる。定期実行の登録内容は高さを制限した表示欄で読み、履歴の右端の列には水平スクロールで移動する。

## 基本設定と詳細設定

基本設定タブでは、公式サイトの対象URLを読み取り専用で表示する。一般設定として編集できるのは、通常実行と定期実行をまとめるデータルート、ファイル命名規則、取得する拡張子、キーワード、取得日の範囲である。データルートを変更すると、通常実行と定期実行の保存予定パスを画面に表示する。「保存済みファイルを再分類...」は、利用可能な場合に確認用プレビューを開く。検索対象や発注機関などの検索条件はメイン画面で扱う。

詳細設定タブではログレベル、ログファイル、最大サイズ、バックアップ数を編集する。一般設定は`config/config.yaml`へ保存し、保存前に入力を検証する。保存に失敗した場合は画面へエラーを表示する。

「デフォルトに戻す」は確認後に一般設定の入力欄へ既定値を読み込む。フッターの「キャンセル」は未保存の一般設定を保存せずに閉じる。定期実行タブで既に完了した追加・編集・削除などの操作は取り消さない。

## 定期実行の管理

定期実行タブは自配置が管理する名前付きの保存条件と、管理外の旧Windowsタスクを別枠に表示する。保存条件には、検索条件、取得・保存条件、実行予定、再試行、通知方針を含める。一覧で条件を選び、追加・複製・編集・削除・有効化／無効化・修復・今すぐ実行と、選択設定または全設定の直近20回の履歴確認を行う。追加・複製・編集・削除・有効切替はその場で登録台帳へ反映する。フッターの「保存」は一般設定用であり、定期実行の操作確定には不要である。

管理対象の設定は、実行中・順番待ち・再試行待機中でも複製、編集、削除、有効化／無効化できる。編集時は確認を取り、開始済み・待機済みの実行は登録時の不変スナップショットで継続し、変更後の条件は次回以降に使用する。削除や無効化の確認画面にも、進行中の実行は継続する旨を示す。削除後も診断用の実行履歴は保持する。

「今すぐ実行」は選択条件のタスクが実行中・順番待ちの場合、または登録・修復が必要な場合には開始できない。選択項目がない場合や管理操作の処理中も、該当するボタンを無効にする。管理外タスクには通常の編集・修復・実行を許可せず、検証済みの旧設定の明示的な取り込みと、実行中でない外部タスクの確認付き解除を別枠で行う。

追加・編集の画面には「実行条件」と「実行予定」のタブを置く。実行条件では検索条件と取得・保存条件を編集し、実行予定では毎日・毎週・毎月、時刻、再試行、スリープ解除、通知方針などを設定する。検索候補の取得と定期実行の状態更新はGUIを止めずに行う。保存時は入力と条件の整合性を検証し、同一条件の別設定があれば警告する。登録台帳の更新競合が起きた場合はエラーを表示し、入力済みの内容を再編集できるようにする。

## 受け入れ確認

- 通常、実行中、順番待ち、再試行待機中の各状態で、管理対象の複製・編集・削除・有効化／無効化が有効であり、重複する「今すぐ実行」は無効になる。
- 実行中に編集・保存しても、開始済みの実行は旧スナップショットで続き、次回以降は新しい条件を使用する。
- 管理外の旧Windowsタスクには通常の管理操作が有効にならない。選択がない場合と操作処理中もボタン状態が適切に変わる。
- 小さい作業領域でも主要ボタンとフッターが見え、各入力欄、登録内容、履歴の右端の列へスクロールで到達できる。
- 一般設定の保存と、定期実行タブで確定済みの操作が別々に扱われる。
